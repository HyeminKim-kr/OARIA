## 상세 프로세스

### Phase 1: 검색 (Search)

```
┌─────────────────────────────────────────────────────────────────┐
│  사용자 입력                                                     │
│  $ uv run python main.py collect -q "neoplasms" -l 10           │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  EuropePMCCollector.search()                                    │
│  ─────────────────────────────                                  │
│  • 쿼리 생성: "neoplasms AND OPEN_ACCESS:Y"                      │
│  • API 호출: europepmc.org/webservices/rest/search              │
│  • 결과 파싱: JSON → Python Dict                                 │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  결과: 논문 메타데이터 리스트                                     │
│  ─────────────────────────────                                  │
│  [                                                              │
│    { pmcid, title, abstract, authors, year, ... },              │
│    { pmcid, title, abstract, authors, year, ... },              │
│    ...                                                          │
│  ]                                                              │
└─────────────────────────────────────────────────────────────────┘
```

### Phase 2: 전문 수집 (Full-text Collection)

```
┌─────────────────────────────────────────────────────────────────┐
│  사용자 입력                                                     │
│  $ uv run python main.py collect-fulltext -q "neoplasms" -l 10  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  EuropePMCCollector.search_with_fulltext()                      │
│  ─────────────────────────────────────────                      │
│  1. search() 호출 → 메타데이터 수집                              │
│  2. 각 논문에 대해:                                              │
│     └─▶ get_fulltext(pmcid) 호출                                │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  get_fulltext(pmcid)                                            │
│  ───────────────────                                            │
│  • API 호출: europepmc.org/.../PMC{id}/fullTextXML              │
│  • XML 파싱: BeautifulSoup으로 섹션 추출                         │
│  • 0.5초 딜레이 (API 부하 방지)                                  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  XML 섹션 파싱                                                   │
│  ─────────────                                                  │
│  <article>                                                      │
│    <abstract>...</abstract>      → full_text_sections.abstract  │
│    <sec sec-type="intro">...</>  → full_text_sections.intro     │
│    <sec sec-type="methods">...</>→ full_text_sections.methods   │
│    <sec sec-type="results">...</>→ full_text_sections.results   │
│    <sec sec-type="discussion">...→ full_text_sections.discussion│
│  </article>                                                     │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│  결과: 전문 포함 논문 데이터                                      │
│  ─────────────────────────────                                  │
│  {                                                              │
│    "pmcid": "PMC12345678",                                      │
│    "title": "...",                                              │
│    "abstract": "...",                                           │
│    "full_text": "전체 텍스트...",                                │
│    "full_text_sections": {                                      │
│      "abstract": "...",                                         │
│      "introduction": "...",                                     │
│      "methods": "...",                                          │
│      "results": "...",                                          │
│      "discussion": "..."                                        │
│    }                                                            │
│  }                                                              │
└─────────────────────────────────────────────────────────────────┘
```

## API 호출 흐름

### 1. 검색 API

```
Request:
GET https://www.ebi.ac.uk/europepmc/webservices/rest/search
    ?query=neoplasms AND OPEN_ACCESS:Y
    &format=json
    &pageSize=10
    &resultType=core

Response:
{
  "resultList": {
    "result": [
      {
        "pmcid": "PMC12345678",
        "title": "...",
        "abstractText": "...",
        "authorList": {...},
        "pubYear": "2024"
      },
      ...
    ]
  }
}
```

### 2. 전문 API

```
Request:
GET https://www.ebi.ac.uk/europepmc/webservices/rest/PMC12345678/fullTextXML

Response:
<?xml version="1.0"?>
<article>
  <front>...</front>
  <body>
    <sec sec-type="intro">
      <title>Introduction</title>
      <p>...</p>
    </sec>
    <sec sec-type="methods">
      <title>Methods</title>
      <p>...</p>
    </sec>
    ...
  </body>
</article>
```
