## 데이터 소스 레퍼런스

### 1. PubMed E-utilities (NCBI) ⭐ 추천

생의학 논문의 표준 데이터베이스. **암 논문 약 550만 건** 보유.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://www.ncbi.nlm.nih.gov/books/NBK25497/ |
| **Base URL** | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` |
| **인증** | API Key 권장 (없이도 사용 가능) |
| **Rate Limit** | 3 req/sec (API Key 있으면 10 req/sec) |
| **데이터 형식** | XML, JSON |
| **전문(Full-text)** | PMC Open Access Subset만 가능 |

**예시 요청:**

```bash
# 암 관련 논문 검색
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=cancer&retmax=10&retmode=json"

# 논문 상세 정보 가져오기
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=12345678&retmode=xml"
```

**Python 라이브러리:**
- `biopython` - Entrez 모듈 제공
- `pymed` - PubMed 검색 전용

```python
from Bio import Entrez

Entrez.email = "your@email.com"
handle = Entrez.esearch(db="pubmed", term="breast cancer", retmax=100)
```

### 2. Europe PMC ⭐ 추천

유럽 생의학 문헌 데이터베이스. **암 논문 약 528만 건** 보유. 텍스트 마이닝 기능 강점.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://europepmc.org/RestfulWebService |
| **Base URL** | `https://www.ebi.ac.uk/europepmc/webservices/rest/` |
| **인증** | 불필요 |
| **Rate Limit** | 명시되지 않음 (합리적 사용) |
| **데이터 형식** | XML, JSON |
| **전문(Full-text)** | Open Access 논문 제공 |

**예시 요청:**

```bash
# 암 관련 논문 검색
curl "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=cancer&format=json&pageSize=10"

# 전문 텍스트 가져오기 (Open Access만)
curl "https://www.ebi.ac.uk/europepmc/webservices/rest/PMC1234567/fullTextXML"
```

**Python 라이브러리:**
- `europepmc` (R 패키지, Python은 직접 REST 호출)

**특징:**
- Annotations API로 gene/protein, disease 등 텍스트 마이닝 결과 제공
- PubMed + PMC + Preprints 통합 검색

### 3. OpenAlex ⭐ 추천

완전 무료 오픈 학술 데이터베이스. **암 논문 약 293만 건** 보유.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://docs.openalex.org/ |
| **Base URL** | `https://api.openalex.org/` |
| **인증** | 불필요 (이메일 파라미터 권장) |
| **Rate Limit** | 100,000 req/day |
| **데이터 형식** | JSON |
| **전문(Full-text)** | 링크 제공 (직접 호스팅 X) |

**예시 요청:**

```bash
# 암 관련 논문 검색
curl "https://api.openalex.org/works?filter=title.search:cancer&per_page=10&mailto=your@email.com"

# 특정 주제(Concept) 필터링
curl "https://api.openalex.org/works?filter=concepts.id:C71924100&per_page=10"
```

**Python 라이브러리:**
- `pyalex` - 공식 Python 클라이언트

```python
from pyalex import Works

works = Works().filter(title={"search": "lung cancer"}).get()
```

**특징:**
- CC0 라이선스 (제한 없이 사용 가능)
- 인용 관계, 저자, 기관 등 풍부한 메타데이터
- DOI, PMID 등 다양한 ID로 조회 가능

### 4. Semantic Scholar

AI 기반 학술 검색 엔진. **2억 건 이상 논문** 보유.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://api.semanticscholar.org/api-docs/ |
| **Base URL** | `https://api.semanticscholar.org/graph/v1/` |
| **인증** | API Key 권장 |
| **Rate Limit** | 1 req/sec (인증 시), 공유풀 (미인증) |
| **데이터 형식** | JSON |
| **전문(Full-text)** | Open Access PDF 링크 제공 |

**예시 요청:**

```bash
# 논문 검색
curl "https://api.semanticscholar.org/graph/v1/paper/search?query=cancer+treatment&limit=10"

# 논문 상세 정보
curl "https://api.semanticscholar.org/graph/v1/paper/DOI:10.1234/example?fields=title,abstract,authors"
```

**Python 라이브러리:**
- `semanticscholar` (PyPI)

```python
from semanticscholar import SemanticScholar

sch = SemanticScholar()
results = sch.search_paper("cancer immunotherapy", limit=10)
```

**특징:**
- SPECTER2 임베딩 제공 (유사 논문 검색에 유용)
- 인용/참조 관계 데이터 풍부

### 5. arXiv API

프리프린트 서버. 암/생물학 분야는 q-bio 카테고리. **암 관련 약 9,800건**.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://info.arxiv.org/help/api/index.html |
| **Base URL** | `https://export.arxiv.org/api/query` |
| **인증** | 불필요 |
| **Rate Limit** | 1 req/3sec |
| **데이터 형식** | Atom/XML |
| **전문(Full-text)** | PDF 직접 다운로드 가능 |

**예시 요청:**

```bash
# 암 관련 논문 검색 (q-bio 카테고리)
curl "https://export.arxiv.org/api/query?search_query=cat:q-bio*+AND+all:cancer&max_results=10"
```

**Python 라이브러리:**
- `arxiv` (PyPI)

```python
import arxiv

search = arxiv.Search(query="cancer AND cat:q-bio*", max_results=10)
for paper in search.results():
    print(paper.title)
```

**특징:**
- PDF 전문 무료 다운로드
- 최신 연구 (프리프린트) 접근 가능
- 생의학 분야는 상대적으로 적음

### 6. ClinicalTrials.gov API

암 임상시험 데이터. **암 관련 약 11만 5천 건**.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://clinicaltrials.gov/data-api/api |
| **Base URL** | `https://clinicaltrials.gov/api/v2/` |
| **인증** | 불필요 |
| **Rate Limit** | 명시되지 않음 |
| **데이터 형식** | JSON |

**예시 요청:**

```bash
# 암 임상시험 검색
curl "https://clinicaltrials.gov/api/v2/studies?query.cond=cancer&pageSize=10"

# 특정 암종 검색
curl "https://clinicaltrials.gov/api/v2/studies?query.cond=lung+cancer&filter.overallStatus=RECRUITING"
```

**특징:**
- 임상시험 프로토콜, 결과 데이터
- 챗봇에서 "현재 진행 중인 임상시험" 안내에 유용

### 7. Crossref API

DOI 메타데이터. **암 관련 약 311만 건**.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://www.crossref.org/documentation/retrieve-metadata/rest-api/ |
| **Base URL** | `https://api.crossref.org/` |
| **인증** | 불필요 (이메일 파라미터 권장) |
| **Rate Limit** | Polite pool 사용 시 빠름 |
| **데이터 형식** | JSON |
| **전문(Full-text)** | 링크만 제공 |

**예시 요청:**

```bash
# 암 관련 논문 메타데이터
curl "https://api.crossref.org/works?query=cancer&rows=10&mailto=your@email.com"

# DOI로 조회
curl "https://api.crossref.org/works/10.1038/nature12831"
```

**특징:**
- 1억 7천만 건 이상 DOI 등록
- 참조문헌, 펀딩 정보 포함
- 전문 텍스트는 없음 (메타데이터만)

### 8. CORE API

오픈 액세스 논문 전문 텍스트. **4억 3천만 건 메타데이터, 4,600만 건 전문**.

| 항목 | 내용 |
|------|------|
| **API 문서** | https://core.ac.uk/services/api |
| **Base URL** | `https://api.core.ac.uk/v3/` |
| **인증** | API Key 필요 |
| **Rate Limit** | 무료: 5 req/10sec |
| **데이터 형식** | JSON |
| **전문(Full-text)** | 제공 |

**특징:**
- 전 세계 기관 리포지토리 통합
- 전문 텍스트 직접 제공
- 무료 티어는 Rate Limit 있음
