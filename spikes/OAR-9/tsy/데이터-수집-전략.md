# 암 논문 데이터 수집 전략

> **OAR-20**: 데이터 수집 전략 정의
>
> 작성일: 2025-12-19

---

## 목표

- **타겟 사용자**: 종양학(Oncology) 연구자
- **서비스**: 암 논문 전문(Full-text) 기반 RAG 챗봇
- **이유**: 연구자는 초록이 아닌 구체적인 수치, 방법론, 세부 결과가 필요

---

## 검색 쿼리 전략

### 고정 쿼리

```
neoplasms AND OPEN_ACCESS:Y
```

- `neoplasms`: 모든 암/종양을 포함하는 MeSH 상위 용어
- `OPEN_ACCESS:Y`: 전문 수집 가능한 OA 논문만

### 대안 쿼리 (단순)

```
cancer AND OPEN_ACCESS:Y
```

### 쿼리 선정 이유

| 옵션 | 장점 | 단점 |
|------|------|------|
| `cancer` | 단순, 직관적 | 노이즈 가능 |
| `neoplasms`[MeSH] | 의학적 정확성 | MeSH 지원 확인 필요 |
| 암 종류별 | 정밀 | 누락 가능성 |

→ **종양학 전체**를 대상으로 하므로 넓은 쿼리 사용

## 핵심 결정

### 단일 소스: Europe PMC

```
여러 소스 (PubMed, OpenAlex, Europe PMC)
    → 같은 논문이 중복됨
    → 데이터 불일치 가능성

단일 소스 (Europe PMC)
    → 중복 없음
    → 일관된 데이터
    → 전문 수집 가능
```

### 왜 Europe PMC인가?

| 기준 | PubMed | Europe PMC | OpenAlex |
|------|--------|------------|----------|
| 메타데이터 | ✅ | ✅ | ✅ |
| 초록 | ✅ | ✅ | ✅ |
| **전문 텍스트** | ❌ | ✅ | ❌ |
| OA 필터링 | ❌ | ✅ | ✅ |
| API 편의성 | 보통 | 좋음 | 좋음 |
| 인증 | 권장 | 불필요 | 불필요 |

**Europe PMC = 메타데이터 + 초록 + 전문 모두 제공**

## 수집 대상

### Open Access 암 논문

```
암 논문 전체:        5,283,298건
암 논문 Open Access: 2,032,444건 (38.5%)
─────────────────────────────────────────
수집 가능:          약 200만 건
```

### Open Access만 수집하는 이유

| 구분 | 초록만 | 전문 포함 |
|------|--------|----------|
| Non-OA | ✅ 가능 | ❌ 유료/불법 |
| **Open Access** | ✅ 가능 | ✅ **무료/합법** |

## 수집 파이프라인

```
┌─────────────────────────────────────────────────────────────┐
│  1. Search API                                              │
│     POST europepmc/search                                   │
│     query: "cancer AND OPEN_ACCESS:Y"                       │
│     → PMCID 목록 확보                                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 메타데이터 수집                                          │
│     - 제목, 초록, 저자, 저널, 연도                           │
│     - 키워드, DOI, PMID                                     │
│     → PostgreSQL 저장                                       │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  3. Full-text API                                           │
│     GET europepmc/PMC{id}/fullTextXML                       │
│     → XML 파싱 → 섹션별 텍스트 추출                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  4. 청킹 + 벡터화                                            │
│     - 섹션별 분리 (Abstract, Methods, Results, Discussion)  │
│     - 임베딩 모델 적용                                       │
│     → Vector DB 저장                                        │
└─────────────────────────────────────────────────────────────┘
```

## 데이터 스키마

### 논문 테이블 (PostgreSQL)

```sql
CREATE TABLE papers (
    id SERIAL PRIMARY KEY,
    pmcid VARCHAR(20) UNIQUE NOT NULL,  -- PMC 기준 ID
    pmid VARCHAR(20),
    doi VARCHAR(100),

    title TEXT NOT NULL,
    abstract TEXT,
    authors JSONB,           -- ["저자1", "저자2", ...]
    journal VARCHAR(500),
    year INTEGER,

    keywords JSONB,          -- ["키워드1", "키워드2", ...]
    mesh_terms JSONB,        -- MeSH 의료 용어

    is_open_access BOOLEAN DEFAULT TRUE,
    full_text_url VARCHAR(500),

    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

### 청크 테이블 (Vector DB 연동)

```sql
CREATE TABLE paper_chunks (
    id SERIAL PRIMARY KEY,
    paper_id INTEGER REFERENCES papers(id),

    section VARCHAR(50),     -- abstract, methods, results, discussion
    chunk_index INTEGER,
    content TEXT NOT NULL,

    embedding VECTOR(1536),  -- 또는 별도 Vector DB

    created_at TIMESTAMP DEFAULT NOW()
);
```

## API 예시

### 검색 (Open Access 암 논문)

```bash
curl "https://www.ebi.ac.uk/europepmc/webservices/rest/search?\
query=cancer%20AND%20OPEN_ACCESS:Y&\
format=json&\
pageSize=100&\
resultType=core"
```

### 전문 텍스트 수집

```bash
curl "https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7654321/fullTextXML"
```
