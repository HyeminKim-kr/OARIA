- Correction/Retraction 논문은 원문 신뢰도에 직접 영향
- Europe PMC API에서 pubTypeList, commentCorrectionList 제공

- [x] europe_pmc.py에서 새 필드 추출
- [x] pubType 필터링 로직 구현
- [x] 관계 처리 로직 구현 (방향성 + 플래그)

## 필터링 규칙

### pubType 기반 처리
| 유형 | 키워드 | 수집 | 임베딩 |
|------|--------|------|--------|
| 완전 드랍 | editorial, commentary, opinion, news, perspective, letter, correspondence | X | X |
| 저장만 | erratum, corrigendum, correction, retraction | O | X |
| 정상 처리 | research-article, review 등 | O | O |

### 관계 방향성
- `for/of/on` → outward (현재 문서가 Correction, link.id가 원문)
- `in` → inward (현재 문서가 원문)

### 플래그 설정
- paper_relations: 모든 관계 저장 (comment 포함)
- papers.has_*: correction/erratum/retraction만 (comment 제외)
