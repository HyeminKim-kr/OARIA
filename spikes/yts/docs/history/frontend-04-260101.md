## Context (배경)

사이드바의 대화 히스토리가 목데이터(mockConversations)로 구현되어 있어 실제 API와 연동 필요.

### 기존 상태

- DB 스키마: 설계 완료 (`conversations`, `messages`, `answer_logs`)
- Backend Models: 구현 완료 (`chat.py`)
- Backend API: 구현 완료 (`ai.py` - `/ai/conversations` CRUD)
- Frontend: 목데이터 사용 중

- [x] `api.ts`에 conversations API 함수 추가
