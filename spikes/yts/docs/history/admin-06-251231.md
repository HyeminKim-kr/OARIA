# ConfigModule 환경변수 검증 추가

> **Category**: admin
> **Date**: 2025-12-31
> **Status**: completed

---

## Context (배경)
- 프로덕션 환경에서 환경변수 누락 시 런타임 에러 발생 가능
- 로컬(development)에서는 디폴트값으로 편하게 개발 가능해야 함
- 프로덕션/스테이징에서는 모든 필수 환경변수가 명시되어야 함

## Solution (해결 방안)
- [x] class-validator를 활용한 환경변수 검증 스키마 작성
- [x] ValidateIf 조건부 검증으로 환경별 필수값 분리
- [x] ConfigModule.forRoot에 validate 함수 연결
- [x] .env.example 업데이트

## Changes (변경 사항)

### 생성된 파일
- `src/config/env.validation.ts` - 환경변수 검증 스키마 및 validate 함수
- `src/config/index.ts` - config 모듈 export

### 수정된 파일
- `src/app.module.ts` - ConfigModule에 validate 함수 연결
- `.env.example` - 전체 환경변수 목록 및 설명 추가

## Notes
- **development/test**: 디폴트값 사용 가능 (선택적 환경변수)
- **production/staging**: 모든 환경변수 필수 (누락 시 서버 시작 실패)
- ValidateIf 데코레이터로 환경별 조건부 검증 구현
