# Backfill Cancel 버그 수정

> **Category**: batch
> **Date**: 2026-01-01
> **Status**: completed

---

## Context (배경)
- Admin에서 Job Cancel 버튼을 눌러도 실제로 작업이 중단되지 않음
- Cancel은 DB 상태만 `cancelled`로 변경하고, Celery 워커는 이를 체크하지 않음
- 결과적으로 cancelled 상태인데도 924/924 완료됨

## Solution (해결 방안)
- [x] `backfill.py`의 `_phase_collect()` 루프에서 Job 상태 체크 추가
- [x] `cancelled` 상태면 루프 중단
- [x] 중단 시 상태 처리 로직 추가 (이미 cancelled이므로 complete_job 호출 안함)

## Changes (변경 사항)
### 수정된 파일
- `batch/src/tasks/backfill.py`
  - `check_job_cancelled()` 함수 추가 (line 223-233)
  - `_phase_collect()` while 루프 시작 시 cancelled 상태 체크 (line 790-797)
  - 최종 처리에서 cancelled 상태 분기 처리 (line 838-848)
