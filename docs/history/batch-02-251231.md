> **Category**: batch
> **Date**: 2025-12-31
> **Status**: completed

---

## Context (배경/근거)

### 현재 문제
- `embed.py`에서 외부 스파이크(OAR-29, OAR-31) 경로를 동적 임포트
- 스파이크는 참고용 코드이며, 서비스 프로젝트에서 직접 임포트하면 안 됨
- 루트 프로젝트가 실제 서비스 공간

### 목표
- OAR-29 (Chunker), OAR-31 (Embedding, Weaviate) 코드를 `batch/src/`로 복사
- 로컬 모듈에서 import하도록 수정

---

## Solution (해결 방안)

### 폴더 구조 변경

**Before:**
```
batch/src/tasks/embed.py
  └── imports from spikes/OAR-29/yts/src/chunker.py
  └── imports from spikes/OAR-31/yts/src/*.py
```

**After:**
```
batch/src/
├── chunker/
│   ├── __init__.py
│   └── chunker.py          # OAR-29에서 복사
├── embedding/
│   ├── __init__.py
│   ├── client.py           # OAR-31 WeaviateClient
│   ├── embeddings.py       # OAR-31 EmbeddingClient
│   └── schema.py           # OAR-31 스키마
└── tasks/
    └── embed.py            # 로컬 모듈에서 import
```

### 작업 항목

- [x] `batch/src/chunker/` 폴더 생성 및 OAR-29 코드 복사
- [x] `batch/src/embedding/` 폴더 생성 및 OAR-31 코드 복사
- [x] `embed.py` 수정: 동적 임포트 제거, 로컬 임포트로 변경
- [x] 구문 검증
