# Service Frontend: 논문 상세 페이지 구현

> **Category**: frontend
> **Date**: 2026-01-15
> **Status**: completed

---

## Context (배경)

- 논문 목록에서 클릭 시 상세 페이지로 이동하는 기능 필요
- PDF 수집이 현재 동작하지 않아 display.json (fulltext) 으로 대체
- alphaXiv 스타일의 논문 뷰어 UI 구현
- S3에 display.json 이 sections/paragraphs 구조로 저장되어 있음

## Solution (해결 방안)

### 접근 방식
1. Backend에 display.json 전체를 반환하는 API 추가
2. Frontend에 /papers/[id] 라우트 생성
3. display.json을 섹션별로 렌더링하는 PaperContent 컴포넌트 구현
4. PaperCard에서 상세 페이지로 연결

### 작업 항목
- [x] Backend: GET /papers/{id}/display API 추가
- [x] Frontend: /papers/[id] 라우트 생성
- [x] Frontend: PaperContent 컴포넌트 (display.json 렌더링)
- [x] Frontend: PaperCard → 상세페이지 네비게이션 연결
- [x] 테스트 (빌드 성공)

## Changes (변경 사항)
