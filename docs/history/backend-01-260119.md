## Context (배경)

- 논문 상세 페이지(`/papers/[id]`)에 AI 채팅봇 기능 필요
- 현재 UI만 존재하고 기능 미구현 상태
- 기존 `/ai/ask`는 전체 컬렉션 대상 - 논문별 채팅은 별도 엔드포인트 필요
- Quick Actions도 함께 구현 (하이라이트&질문, 맥락 추가, 요약 생성, 인용 정보)

## API Endpoints

| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/ai/papers/{paper_id}/ask` | SSE 스트리밍 질의응답 |
| GET | `/ai/papers/{paper_id}/conversations` | 논문별 대화 목록 |
| GET | `/ai/papers/{paper_id}/conversations/{id}/messages` | 대화 메시지 조회 |
| POST | `/ai/papers/{paper_id}/summarize` | 요약 생성 |
| POST | `/ai/papers/{paper_id}/citation` | 인용 정보 생성 |

## Notes

- 기존 `/ai/ask` API와 분리하여 `/ai/papers/{paper_id}/ask` 엔드포인트 생성
- Gate 1 (Domain Classifier) 미적용 (이미 논문 컨텍스트 내)
- 논문별 대화 저장을 위해 Conversation 테이블에 paper_id 추가
- 마이그레이션 실행 필요: `alembic upgrade head`
- Citation 서비스는 LLM 미사용 (순수 템플릿 기반)
- Summary 서비스는 LLM 사용 (gpt-4o-mini)
