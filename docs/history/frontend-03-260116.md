# PDF.js + Next.js 15 호환성 수정

> **Category**: frontend
> **Date**: 2026-01-16
> **Status**: completed

---

## Context (배경)

PDF 뷰어 사용 시 Next.js 15 환경에서 에러 발생:
```
Object.defineProperty called on non-object
at (app-pages-browser)/./node_modules/pdfjs-dist/build/pdf.mjs
```

원인: pdfjs-dist가 SSR 중 브라우저 전용 객체에 접근

## Solution (해결 방안)

### 접근 방식: 동적 Import + 클라이언트 전용 로딩

```
기존:
  import { Document, Page, pdfjs } from "react-pdf";
  pdfjs.GlobalWorkerOptions.workerSrc = ...;  // SSR에서 에러

변경:
  useEffect(() => {
    const pdfjs = await import("pdfjs-dist");
    pdfjs.GlobalWorkerOptions.workerSrc = ...;  // 클라이언트에서만 실행
    const reactPdf = await import("react-pdf");
    // ...
  }, []);
```

## 핵심 변경 내용

```tsx
// 상태 추가
const [pdfReady, setPdfReady] = useState(false);
const [PdfComponents, setPdfComponents] = useState<{ Document: any; Page: any } | null>(null);

// 클라이언트에서만 로드
useEffect(() => {
  const loadPdf = async () => {
    const pdfjs = await import("pdfjs-dist");
    pdfjs.GlobalWorkerOptions.workerSrc = `//unpkg.com/pdfjs-dist@${pdfjs.version}/build/pdf.worker.min.mjs`;

    const reactPdf = await import("react-pdf");
    setPdfComponents({ Document: reactPdf.Document, Page: reactPdf.Page });
    setPdfReady(true);
  };
  loadPdf();
}, []);

// 조건부 렌더링
{pdfReady && PdfComponents && (
  <PdfComponents.Document ...>
    <PdfComponents.Page ... />
  </PdfComponents.Document>
)}
```

## Notes

- CSS import는 `"use client"` 지시어가 있으므로 정적 import로 유지
- Worker URL은 unpkg CDN 사용 (버전 자동 매칭)
