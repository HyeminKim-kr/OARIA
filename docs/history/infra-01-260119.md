# dev.sh 스크립트 개선 - restart 및 개별 컨테이너 제어 추가

> **Category**: infra
> **Date**: 2026-01-19
> **Status**: completed

---

## Context (배경)

현재 `scripts/dev.sh` 스크립트의 문제점:
- 개별 제어 섹션(`docker`, `admin`, `service`)에 restart 옵션 없음
- 로컬 개발 모드 직접 실행 명령어 없음 (인터랙티브만 존재)
- 개별 Docker 컨테이너 제어 기능 없음
- 리빌드 옵션 없음

## Solution (해결 방안)

### 추가한 명령어

- [x] `local start/stop/restart` - 로컬 개발 모드 직접 실행
- [x] `docker restart` - 인프라 restart
- [x] `docker-dev rebuild` - 개발 모드 리빌드
- [x] `prod rebuild` - 프로덕션 모드 리빌드
- [x] `admin restart` - Admin 로컬 restart
- [x] `service restart` - Service 로컬 restart
- [x] `container <name> start/stop/restart/rebuild/logs` - 개별 컨테이너 제어
- [x] help 메시지 개선 (상세한 설명, 예시 포함)

## Changes (변경 사항)

### 수정된 파일
- `scripts/dev.sh` - 전체 개선
  - 새 함수: `restart_docker()`, `rebuild_docker_prod()`, `rebuild_docker_dev()`, `restart_admin()`, `restart_service_local()`, `container_control()`, `show_help()`
  - case문 업데이트: `local`, `container` 명령어 추가, 기존 명령어에 restart/rebuild 추가
  - help 메시지 전면 개선: 카테고리별 정리, URL 목록, 사용 예시 추가

### 최종 명령어 구조

```bash
# 기본 명령어 (인터랙티브)
./dev.sh start|stop|restart|status|logs|monitor

# 로컬 개발 모드
./dev.sh local start|stop|restart

# Docker 개발 모드
./dev.sh docker-dev start|stop|restart|rebuild

# Docker 프로덕션 모드
./dev.sh prod start|stop|restart|rebuild

# 인프라만
./dev.sh docker start|stop|restart

# 로컬 서비스 개별
./dev.sh admin start|stop|restart
./dev.sh service start|stop|restart

# 개별 컨테이너
./dev.sh container <name> start|stop|restart|rebuild|logs

# 유틸리티
./dev.sh install|migrate|help
```

## Notes
- 컨테이너 이름은 `oaria-` 접두사 자동 처리
- rebuild는 `--no-cache` 옵션으로 완전 리빌드
- help 명령어로 상세한 도움말 확인 가능
