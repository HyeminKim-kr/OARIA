## Root Cause Analysis (원인 분석)
### 확인된 사항
1. UUID는 Weaviate 자동 생성이 아닌 `uuid5()`로 결정적 생성
2. 같은 paper_id + section + chunk_index → 항상 같은 UUID
3. 논문 수집 로직이 기존 논문을 "스킵"이 아닌 "업데이트" 방식

### 가능한 원인 (추가 조사 필요)
1. 같은 논문이 두 번 처리되는 경우 (동시 실행)
2. `get_papers_for_embedding()` 쿼리에서 DISTINCT 없이 JOIN으로 중복
3. 임베딩 도중 실패 후 Weaviate에 부분 데이터 남음
