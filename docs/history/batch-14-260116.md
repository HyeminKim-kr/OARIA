# Backfill Heartbeat Stale 문제 해결

> **Category**: batch
> **Date**: 2026-01-16
> **Status**: completed

---

## Context (배경)

Backfill 작업이 "Job was stale (no heartbeat for 10 minutes)" 에러로 반복 실패:
- Admin Scheduler가 5분마다 stale job 체크
- `locked_at`이 10분 이상 업데이트되지 않으면 failed로 변경
- 같은 쿼리가 계속 재시도되어 여러 번 실행됨

문제 원인:
1. Search: 100개 batch마다만 heartbeat 업데이트
2. Europe PMC API가 느리면 100개 모으는데 10분+ 걸릴 수 있음
3. Collect/Embed: 대기 중에는 heartbeat 업데이트 없음

## Solution (해결 방안)

### 시간 기반 Heartbeat 추가

```python
HEARTBEAT_INTERVAL_SECONDS = 30  # 30초마다 heartbeat

def update_heartbeat(conn, job_id):
    """Heartbeat만 업데이트 (locked_at 갱신)"""
    cur.execute("UPDATE batch_jobs SET locked_at = NOW() WHERE id = %s")
```

### 각 Phase에 적용

1. **_phase_search**: 검색 결과마다 시간 체크, 30초마다 heartbeat
2. **_phase_collect**: 대기 중에도 30초마다 heartbeat
3. **_phase_embed**: 대기 중에도 30초마다 heartbeat

## Changes (변경 사항)

### 수정된 파일

- `batch/src/tasks/backfill.py`

  - `update_heartbeat()` 함수 추가
  - `_phase_search`: 검색 루프에 시간 기반 heartbeat 추가
  - `_phase_collect`: 대기 루프에 시간 기반 heartbeat 추가
  - `_phase_embed`: 대기 루프에 시간 기반 heartbeat 추가

## Notes

- Admin Scheduler: 10분 timeout
- Batch Heartbeat: 30초 간격
- 충분한 안전 마진 (30초 × 20회 = 10분)
- 배치 처리 후에도 heartbeat 갱신
