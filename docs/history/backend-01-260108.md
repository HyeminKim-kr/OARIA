# RAG 멀티 파이프라인 설계 및 구현

> **Category**: backend
> **Date**: 2026-01-08
> **Status**: completed

---

## Context (배경)

현재 RAG 시스템의 한계:
- 청킹/임베딩 전략이 인덱싱 시점에 고정됨
- 다른 전략을 테스트하려면 전체 재인덱싱 필요
- Lab에서 청킹/임베딩 전략 비교 불가

목표:
- 청킹/임베딩 전략을 Lab에서 자유롭게 비교할 수 있도록 개선
- 프로덕션 안정성 유지하면서 실험 유연성 확보

## Solution (해결 방안)

### 핵심 아이디어
- 쿼리 타입을 production/sample로 구분
- 샘플 쿼리로 수집된 논문만 멀티 전략 임베딩
- Admin에 임베딩 관리 페이지 추가

### 구현 태스크
- [x] Phase 1: DB 스키마 설계 및 마이그레이션
- [x] Phase 2: 샘플 임베딩 CRUD API
- [x] Phase 2: Weaviate 멀티 컬렉션 지원
- [x] Phase 3: Admin UI - 임베딩 관리 페이지
- [x] Phase 3: Lab 샘플 데이터 소스 선택 기능
