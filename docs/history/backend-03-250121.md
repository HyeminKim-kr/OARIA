## Context (배경)

Study Plan Agent의 핵심 기능(13개 노드, 3개 루프)은 완료되었으나, 설계문서 Section 6의 DB 저장 기능이 구현되지 않은 상태였습니다.

- 생성된 실험 계획서가 저장되지 않음
- 사용자가 과거 기록을 확인할 수 없음
- 랜딩 페이지가 단순 목록 형태로 SciSpace 스타일 도입 필요
