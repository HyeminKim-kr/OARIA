# 시스템 상태 모니터링 및 재처리 기능 추가

> **Category**: admin
> **Date**: 2025-12-31
> **Status**: completed

---

## Context (배경)
- Celery 워커, Weaviate 등 서비스가 장애 시 관리자가 상태를 파악하기 어려움
- 임베딩 작업이 대기 상태로 멈춰있어도 알 수 없음
- 장애 복구 후 수동으로 재처리를 트리거할 방법이 없음

## Solution (해결 방안)
- [x] Admin Backend에 System 모듈 추가
  - [x] /system/health - 전체 서비스 상태 확인
  - [x] /system/workers - Celery 워커 상태 조회
  - [x] /system/queues - 큐 상태 조회
  - [x] /system/trigger/embedding - 임베딩 수동 트리거
  - [x] /system/trigger/reembedding - 재처리 수동 트리거
- [x] Admin Frontend 대시보드에 시스템 상태 컴포넌트 추가
  - [x] 서비스별 상태 카드 (PostgreSQL, Redis, Weaviate, MinIO, Celery)
  - [x] 임베딩 수동 트리거 버튼
