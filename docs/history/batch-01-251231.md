> **Category**: batch

## Context (배경/근거)

### 현재 문제
- 수집(Backfill) 완료 후 임베딩(Embed)까지 최대 1시간 지연
- Beat 스케줄이 매시 정각에만 실행되기 때문

### 목표
- 수집 완료 즉시 임베딩 태스크 자동 트리거
- Beat는 안전망(누락분 처리)으로 유지

### 관련 설계
- `docs/admin/embedding-pipeline.md` - 체이닝 설계 문서
- `docs/admin/architecture.md` - 전체 아키텍처

---

## Solution (해결 방안)

### 접근 방식

`run_backfill` 태스크 완료 후 `run_embed.delay(query_id)` 호출

```python
# batch/src/tasks/backfill.py
from .embed import run_embed

@app.task(bind=True, queue="backfill")
def run_backfill(self, query_id: str) -> dict:
    result = asyncio.run(run_backfill_async(query_id))

    # 수집 성공 시 임베딩 트리거
    if result.get("completed", 0) > 0:
        run_embed.delay(query_id)
        logger.info("embed_triggered_after_backfill", query_id=query_id)

    return result
```
