# Sample Embedding Resume 기능 구현

> **Category**: batch
> **Date**: 2026-01-08
> **Status**: in_progress

---

## Context (배경)

### 문제점

Docker 컨테이너 재빌드 또는 예기치 않은 중단 시:

1. **진행 중 작업 손실**: 처리 중이던 임베딩이 "processing" 상태로 멈춤
2. **재시작 불가**: status가 "pending" 또는 "failed"일 때만 실행 가능
3. **중복 처리**: 처음부터 다시 시작하면 이미 임베딩된 논문도 재처리

### 해결 방향

- "processing" 상태에서도 재시작(Resume) 가능
- Weaviate에서 이미 처리된 paper_id 조회
- 이미 처리된 논문 건너뛰기

---

## Solution (해결 방안)

### 접근 방식

1. Weaviate 컬렉션에서 이미 임베딩된 paperId 목록 조회
2. 조회된 paperId를 제외한 논문만 처리
3. "processing" 상태도 재시작 허용 (resume)
4. 기존 chunk_count를 유지하면서 누적

### 작업 항목

- [x] `get_embedded_paper_ids()` 함수 추가
- [x] `run_sample_embed` 태스크에서 "processing" 상태 허용
- [x] 이미 처리된 논문 필터링 로직 추가
- [x] 기존 paper_count, chunk_count 누적 로직 추가
- [ ] Docker 재빌드 및 테스트
