> **Category**: admin

> **Status**: completed

## Context (배경)

- `lab/page.tsx`가 1555줄로 너무 커서 유지보수가 어려움
- 다른 페이지들도 300~500줄 수준으로 리팩토링 필요
- 일관된 페이지 구조화 패턴 수립 필요

### 리팩토링 전 페이지 크기

| 파일 | 라인 수 |
|------|---------|
| lab/page.tsx | 1555줄 |

| papers/[id]/page.tsx | 342줄 |
| jobs/[id]/page.tsx | 310줄 |
| papers/page.tsx | 304줄 |

## Solution (해결 방안)

### 구조화 패턴

```
app/{page}/
├── page.tsx              # ~160줄, 조합만
├── _components/          # 페이지 전용 컴포넌트
│   ├── index.ts          # barrel export
│   └── *.tsx
├── _hooks/               # 페이지 전용 훅
│   └── *.ts
└── _lib/                 # 상수, 타입, 유틸
    ├── constants.ts
    ├── types.ts
    └── utils.ts
```

### 생성된 파일

**_lib/ (타입, 상수, 유틸)**
- `_lib/types.ts` - 타입 정의
- `_lib/constants.ts` - 상수 정의
- `_lib/utils.ts` - 유틸 함수
- `_lib/index.ts` - barrel export

**_hooks/ (커스텀 훅)**
- `_hooks/useLabExperiment.ts` - 테스트 실행 로직
- `_hooks/useLabHistory.ts` - 히스토리 조회/삭제
- `_hooks/useLabStats.ts` - 통계 조회
- `_hooks/useLabFeedback.ts` - 피드백 저장
- `_hooks/index.ts` - barrel export

**_components/ (UI 컴포넌트)**
- `_components/Tooltip.tsx` - 툴팁 컴포넌트
- `_components/LabHeader.tsx` - 헤더 및 상태 배지
- `_components/LabStatsPanel.tsx` - 통계 패널
- `_components/LabHelpPanel.tsx` - 도움말 패널
- `_components/LabHistoryPanel.tsx` - 히스토리 패널
- `_components/LabConfigForm.tsx` - 설정 폼
- `_components/LabSearchResults.tsx` - 검색 결과
- `_components/LabGenerateResults.tsx` - 답변 생성 결과
- `_components/LabCompareResults.tsx` - A/B 비교 결과
- `_components/LabErrorState.tsx` - 에러 상태
- `_components/LabEmptyState.tsx` - 빈 상태
- `_components/index.ts` - barrel export

### 수정된 파일
- `page.tsx` - 1555줄 → 160줄로 축소

## Notes

- `_` prefix 폴더는 Next.js 라우팅에서 제외됨
- barrel export (index.ts)로 깔끔한 import 유지
- 공용 컴포넌트(Tooltip)는 추후 components/ 로 이동 가능
- 다른 페이지도 같은 패턴으로 리팩토링 가능
