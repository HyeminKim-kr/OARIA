# 논문 채팅봇 디버깅 로깅 및 비동기 최적화

> **Category**: backend
> **Date**: 2026-01-19
> **Status**: completed

---

## Context (배경)

- 논문 상세 페이지 채팅봇(`/ai/papers/{paper_id}/ask`)에서 응답 지연 또는 실패 발생
- "이 논문의 핵심이 뭐야" 질문 시 답변이 느리거나 실패하는 것으로 보고됨
- 원인 파악을 위한 디버깅 로깅 필요
- Weaviate 동기 클라이언트가 async 컨텍스트에서 블로킹되는 잠재적 이슈 확인

## Solution (해결 방안)

### 1. paper_rag_service.py 로깅 강화
- [x] 각 파이프라인 단계별 타이밍 측정
  - Embedding: 임베딩 생성 시간
  - Weaviate Search: 검색 시간 및 결과 개수
  - Rerank: 재정렬 시간 (활성화 여부 표시)
  - Parent Retrieval: 부모 섹션 확장 시간
  - Total: 전체 소요 시간

### 2. paper_chat.py 에러 핸들링 강화
- [x] RAG 검색 단계에 상세 에러 로깅
- [x] LLM 스트리밍 단계에 상세 에러 로깅
- [x] 첫 토큰 수신 시간 측정
- [x] 전체 요청 타이밍 로깅

### 3. weaviate_service.py 비동기 최적화
- [x] `asyncio.to_thread()` 기반 비동기 래퍼 추가
  - `search_hybrid_by_paper_async()`
  - `search_hybrid_by_papers_async()`
  - `get_chunks_by_paper_and_section_async()`
- [x] 연결 시간 로깅 추가
- [x] paper_rag_service에서 비동기 래퍼 사용하도록 수정

## Notes

- 로깅 레벨 설정에 따라 `logger.debug()` 출력 여부 결정
- 병목 지점 파악 후 추가 최적화 가능

  - Parent Retrieval이 느리면: 캐싱 고려
- 향후 질문 유형 분류 기능 추가 고려 (일반적 질문은 RAG 스킵)
