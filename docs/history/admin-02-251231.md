# Flower API 보안 인증 추가

> **Category**: admin
> **Date**: 2025-12-31
> **Status**: completed

---

## Context (배경)
- 현재 Flower API가 FLOWER_UNAUTHENTICATED_API=true로 인증 없이 노출됨
- 프로덕션 환경에서는 보안상 인증이 필수
- 환경별(dev/prod) 설정 분리 필요

## Solution (해결 방안)
- [x] Flower에 Basic Auth 적용 (--basic_auth)
- [x] Admin Backend에서 Basic Auth 헤더로 Flower API 호출
- [x] 환경변수로 개발/프로덕션 분리
- [x] .env.example 업데이트

## Changes (변경 사항)

### 수정된 파일
- `docker-compose.yml` - Flower에 --basic_auth 옵션 추가
- `admin/backend/src/modules/system/system.service.ts` - getFlowerAuthHeaders() 헬퍼 추가, 모든 Flower API 호출에 Basic Auth 헤더 포함
- `.env.example` - FLOWER_USER, FLOWER_PASSWORD 환경변수 추가
