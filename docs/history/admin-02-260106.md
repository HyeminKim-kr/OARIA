# RAG Lab 고도화 - Reranker 및 피드백 시스템

> **Category**: admin
> **Date**: 2026-01-06
> **Status**: completed

---

## Context (배경)

RAG Lab Phase 1, 2 기본 기능 구현 완료 후, 품질 평가를 더 정확하게 하기 위한 고도화 작업.

### 현재 문제점
1. "테스트" 같은 무관한 쿼리에도 0.7 점수로 결과가 나옴 (벡터 검색 특성)
2. 사용자가 결과의 실제 관련성을 판단하기 어려움
3. 피드백이 DB에 저장되지 않아 품질 개선 데이터 수집 불가

### 해결 방향
1. Reranker로 실제 관련성 평가 (BGE Cross-Encoder)
2. 점수 임계값으로 관련 없는 결과 필터링/경고
3. 피드백 DB 저장으로 품질 데이터 수집
