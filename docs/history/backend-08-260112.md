## Context (배경)

사용자 쿼리가 Oncology(암 연구) 도메인인지 분류하는 Gate 1 기능 구현.
Off-domain 쿼리(Cardiology, Neurology 등)가 RAG 파이프라인에 진입하는 것을 경고.

### 관련 지라 태스크
- OAR-24: PubMedBERT 모델 로딩 및 추론 구현
- OAR-25: 도메인 Classification Head 구현
- OAR-26: Gate 1 API 엔드포인트 구현
- OAR-27: 도메인 분류 테스트 데이터셋 구축
- OAR-28: 거절 메시지 템플릿 구현
- OAR-30: PubMedBERT Embedder 구현

### 결정사항
- 분류 방식: Zero-shot Classification (학습 데이터 없음)
- 실패 처리: 경고 로그 남기고 RAG 진행 (Block하지 않음)
