## Notes

### API 엔드포인트

| Method | Path | 설명 |
|--------|------|------|
| POST | `/agent-jobs/` | 새 작업 생성 |
| GET | `/agent-jobs/` | 작업 목록 |
| GET | `/agent-jobs/{id}` | 작업 상세 |
| GET | `/agent-jobs/{id}/stream` | SSE 진행 스트림 |
| POST | `/agent-jobs/{id}/approve` | 승인 제출 |
| POST | `/agent-jobs/{id}/cancel` | 작업 취소 |
| POST | `/agent-jobs/{id}/retry` | 재시도 |
| GET | `/notifications/` | 알림 목록 |
| GET | `/notifications/stream` | SSE 알림 스트림 |
| POST | `/notifications/{id}/read` | 읽음 처리 |
| POST | `/notifications/read-all` | 전체 읽음 |

### 상태 머신

```
PENDING → QUEUED → RUNNING → WAITING_APPROVAL → APPROVED → RUNNING → COMPLETED
                      ↓                                        ↓
                   FAILED ←─────────────────────────────────────┘
```

### 해결된 이슈
- `metadata` → `extra_data` (SQLAlchemy reserved word)
- `references` → quoted in SQL (PostgreSQL reserved word)
- Wrong import path for NotificationCreateInternal

### Deprecated 엔드포인트 (/study-plan/*)
| 기존 | 대체 |
|------|------|
| `POST /study-plan/generate` | `POST /agent-jobs/` + `GET /agent-jobs/{id}/stream` |
| `POST /study-plan/generate-v3` | `POST /agent-jobs/` (agent_type: study_plan_v3) |
| `POST /study-plan/generate-v3-stream` | `POST /agent-jobs/` + `GET /agent-jobs/{id}/stream` |
| `POST /study-plan/save` | 자동 저장 (agent_jobs 테이블) |
| `GET /study-plan/history` | `GET /agent-jobs/` |

### 승인 재개 로직
1. 승인 후 `schedule_job_execution()` 호출
2. `AgentJobExecutor.execute()`에서 APPROVED 상태 감지
3. `_resume_after_approval()` 실행:
   - step_results에서 상태 재구성
   - synthesize_plan_v3 직접 호출
   - 완료 처리 및 알림 전송
