## API 엔드포인트

### PDF 관련
- `GET /papers/by-paper-id/{paper_id}/pdf/url` - PDF Presigned URL (string paper_id)
- `GET /papers/by-paper-id/{paper_id}/has-pdf` - PDF 존재 여부 확인
- `GET /papers/{paper_id}/pdf` - PDF 리다이렉트 (UUID)
- `GET /papers/{paper_id}/pdf/url` - PDF Presigned URL (UUID)

### Citations 관련
- `GET /papers/{paper_id}/citations` - 이 논문을 인용한 논문 목록
- `GET /papers/{paper_id}/references` - 이 논문이 인용한 논문 목록
- `GET /papers/{paper_id}/citation-stats` - 인용 통계

## Notes

- PDF는 Open Access 논문만 다운로드 가능 (PMC FTP)
- Europe PMC는 Similar Articles API를 제공하지 않아 Citations/References로 대체
- PDF 용량 제한: 100MB
- PDF 수집은 환경변수 `COLLECT_PDF=true`로 활성화
- Citations 수집은 환경변수 `COLLECT_CITATIONS=true`로 활성화
