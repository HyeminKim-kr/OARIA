# RAG Lab UI 재설계 - 데이터 소스 기반 전략 선택

> **Category**: admin
> **Date**: 2026-01-16
> **Status**: completed

---

## Context (배경)

RAG Lab 페이지에서 UI 일관성 문제 발생:
1. **Reranker 중복**: 상단 전략 선택 패널과 하단 검색 파라미터에 모두 Reranker 드롭다운 존재
2. **역할 혼란**: Chunker/Embedder가 비활성화되어 있지만 샘플 임베딩 선택 시 변경됨
3. **개념 분리 필요**: 인덱싱 설정(고정) vs 검색 설정(가변) 구분 필요

## Solution (해결 방안)

### 핵심 개념 분리

| 구분 | 설정 | 변경 시점 |
|------|------|----------|
| **데이터 소스** | Chunker, Embedder | 데이터 생성 시 (고정) |
| **검색 설정** | Retriever, Reranker, Classifier | 검색 시 (가변) |
| **검색 파라미터** | limit, alpha | 검색 시 (가변) |

### 새 구조

```
┌─ 데이터 소스 선택 ──────────────────────────────────┐
│ ○ 프로덕션                                         │
│     semantic_section_700t + openai_3small_1536d    │
│ ○ 샘플: test_query                                 │
│     paragraph_500t + bge_m3                        │
└───────────────────────────────────────────────────┘

┌─ 검색 설정 ─────────────────────────────────────────┐
│ Retriever: [hybrid ▼]                              │
│ Reranker: [bge ▼] (또는 none)                      │
│ Classifier: [none ▼]                               │
└───────────────────────────────────────────────────┘

┌─ 검색 파라미터 ─────────────────────────────────────┐
│ 결과 개수: [10]                                    │
│ Alpha: 0.70 ════════════●════════                  │
└───────────────────────────────────────────────────┘
```

## Changes (변경 사항)

### 타입 정의 (`_lib/types.ts`)
- `DataSourceConfig` 인터페이스 추가 (type, collectionName, chunker, embedder)
- `SearchSettings` 인터페이스 추가 (retriever, reranker, classifier)
- `SearchConfig` 수정: dataSource 필드로 통합
- `LabConfig` 수정: 새 구조 + 레거시 호환 필드 유지

### 상수 (`_lib/constants.ts`)
- `DEFAULT_PRODUCTION_DATA_SOURCE` 추가
- `DEFAULT_SEARCH_SETTINGS` 추가
- `DEFAULT_SEARCH_CONFIG` 업데이트
- `DEFAULT_CONFIG` 업데이트

### 컴포넌트

- **DataSourceSelector.tsx** - 라디오 리스트로 변경, Chunker+Embedder 정보 표시
  - compact 모드 추가 (A/B 비교용)
- **SearchSettingsPanel.tsx** - 새로 생성 (StrategySelectionPanel 대체)
  - Retriever, Reranker, Classifier만 포함
- **LabConfigForm.tsx** - Reranker 드롭다운 제거, strategies prop 제거
- **SearchConfigPanel.tsx** - DataSourceSelector(compact) 사용, Reranker 제거

### 훅 (`useLabExperiment.ts`)
- `updateSearchSettings` 함수 추가
- `updateDataSource` 시그니처 변경 (DataSourceConfig 사용)
- API 호출 시 새 구조에서 기존 API 형식으로 변환

### 페이지 (`page.tsx`)
- DataSourceSelector를 상단으로 이동
- SearchSettingsPanel 사용
- LabConfigForm에서 strategies prop 제거

## Notes

- **레거시 호환성**: 기존 `selectedStrategies`, `collectionName` 필드 유지
- **API 호환성**: 백엔드 API는 변경 없음 (프론트에서 변환)
- **StrategySelectionPanel**: 삭제하지 않고 유지 (레거시 호환)
