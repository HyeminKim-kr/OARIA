## Changes (변경 사항)

### papers 모듈

#### 생성된 파일
- `src/modules/papers/types.ts` - 타입/enum 정의
  - `PaperStatusEnum` (collected, chunked, indexed)
  - `EmbeddingStatusEnum` (not_started, pending, processing, completed, failed)
  - `PaperSearchOptions`, `PaginatedResult`, `PaperStats`, `EmbedTriggerResult`, `FulltextResult` interfaces

- `src/modules/papers/dto/index.ts` - class-validator DTOs
  - `FindAllPapersQueryDto` - 검색/필터링 Query 파라미터
  - `GetRecentPapersQueryDto` - 최근 논문 조회
  - `TriggerEmbedAllQueryDto` - 전체 임베딩 트리거
  - `TriggerEmbedByQueryQueryDto` - 쿼리별 임베딩 트리거
  - `TriggerReembedQueryDto` - 재임베딩 트리거

#### 수정된 파일
- `src/modules/papers/papers.controller.ts`
  - Query 파라미터에 DTO 적용
  - 명시적 반환 타입 추가
  - ApiBearerAuth 데코레이터 추가

- `src/modules/papers/papers.service.ts`
  - types.ts에서 enum/interface import
  - 문자열 리터럴 대신 enum 사용
  - 명시적 반환 타입 적용

### collection-jobs 모듈

#### 생성된 파일
- `src/modules/collection-jobs/types.ts` - 타입/enum 정의
  - `JobTypeEnum` (backfill, incremental, repair)
  - `JobStatusEnum` (pending, running, completed, failed, partial, delayed, cancelled, retried)
  - `ErrorStageEnum` (search, download, parse, save)
  - `JobSearchOptions`, `JobErrorOptions`, `JobStats`, `JobErrorStats`, `TaskTriggerResult` interfaces

- `src/modules/collection-jobs/dto/index.ts` - class-validator DTOs
  - `FindAllJobsQueryDto` - Job 목록 조회
  - `GetJobErrorsQueryDto` - Job 에러 조회

#### 수정된 파일
- `src/modules/collection-jobs/collection-jobs.controller.ts`
  - Query 파라미터에 DTO 적용
  - 명시적 반환 타입 추가
  - ApiBearerAuth 데코레이터 추가

- `src/modules/collection-jobs/collection-jobs.service.ts`
  - types.ts에서 enum/interface import
  - `as any` → `JobStatusEnum as JobStatus` 패턴으로 개선
  - BadRequestException import 추가

### auth 모듈

#### 수정된 파일
- `src/modules/auth/dto/index.ts`
  - `AdminUserDto.status`: `string` → `AdminStatus` enum
  - `AdminUserDto.role`: `string` → `AdminRole` enum
  - `PendingApprovalResponseDto.status`: `string` → `AdminStatus` enum
  - `lastLoginAt`: nullable 타입 명시 (`Date | null`)

### scheduler 모듈

#### 수정된 파일
- `src/modules/scheduler/scheduler.service.ts`
  - `JobStatusEnum` import 추가
  - `'running' as any` → `JobStatusEnum.RUNNING as JobStatus`
  - `'failed' as any` → `JobStatusEnum.FAILED as JobStatus`
  - `'pending' as any` → `JobStatusEnum.PENDING as JobStatus`
  - `'cancelled' as any` → `JobStatusEnum.CANCELLED as JobStatus`
  - error 객체 타입 체크 추가 (`error instanceof Error`)
  - 메서드 반환 타입 `Promise<void>` 명시
