## Notes

### 하이라이트 질문 흐름
```
텍스트 선택 → "하이라이트 & 질문" 클릭
    ↓
sendMessage(질문, { highlightContext: 선택텍스트 })
    ↓
Backend: highlight_context 파라미터로 수신
    ↓
RAG 검색 시 활용 (기존 로직)
```

### 맥락 추가 흐름
```
질문 입력 → "맥락 추가" 클릭
    ↓
sendMessage(질문, { includeRelated: true })
    ↓
Backend: similar_papers_service.get_vector_similar(paper_id, limit=3)
    ↓
related_ids = ["pmc:PMC...", "pmc:PMC...", ...]
    ↓
paper_rag_service.retrieve_with_related(paper_id, related_ids, ...)
    ↓
현재 논문 + 유사 논문에서 RAG 검색
```

### 결정 사항
| 항목 | 결정 |
|------|------|
| 유사 논문 조회 전략 | `vector` (Weaviate 벡터 유사도) |
| 관련 논문 개수 | 3개 |
| 참조 논문 목록 UI 표시 | 표시 안함 |
