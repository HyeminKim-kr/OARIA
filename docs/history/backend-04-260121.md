# Study Plan Agent v3 - 3-Tier Search & Decision Points

> **Category**: backend
> **Date**: 2026-01-21
> **Status**: in_progress

---

## Context (배경)

Study Plan Agent v2.1은 13개 노드와 3개 루프로 구성된 가설 기반 실험 설계 에이전트.
현재 자율성이 약 30% 수준으로, "LLM-augmented workflow"에 가까움.

이번 v3에서는 에이전트 자율성을 강화:
1. **3-tier 검색 스택**: RAG → Europe PMC → Tavily Web
2. **3개 Decision Point**: DP1(검색 승격), DP2(Critique 전략), DP3(Plan A/B)
3. **예산 관리**: Redis 기반 사용량 추적 + 캐시
