## Architecture

### LangGraph Graph Flow
```
START → initialize → reason ←──────┐
                       ↓           │
                    execute        │
                       ↓           │
                    observe        │
                       ↓           │
                  check_goal ──────┘ (continue)
                       ↓ (done/error)
                   finalize → END
```

### 주요 설계 결정
1. **Factory 함수 패턴**: reason, execute, check_goal 노드는 의존성 주입을 위해 팩토리 함수 사용
2. **State 변환**: WorkingMemory ↔ LangGraph TypedDict 간 변환 레이어 구현
3. **SSE 호환성**: pending_events 패턴으로 기존 프론트엔드 100% 호환
4. **Dual Mode**: USE_LANGGRAPH 환경변수로 레거시/LangGraph 모드 전환
