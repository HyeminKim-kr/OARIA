# Study Plan Agent v4 - ReAct 기반 에이전트 구현

> **Category**: backend
> **Date**: 2026-01-22
> **Status**: completed

---

## Context (배경)

v3까지는 하드코딩된 LangGraph 워크플로우 기반으로 동작했으나,
진정한 "에이전트"로 발전시키기 위해 ReAct (Reasoning + Acting) 패턴 기반의
v4 아키텍처를 설계하고 구현함.

v4의 핵심 특징:
- LLM이 동적으로 다음 행동 결정
- 15개 이상의 도구 중 필요한 것을 자율 선택
- 실패 시 자동 대안 탐색 및 복구
- 장기 메모리를 통한 학습

## Notes

- v3 API는 그대로 유지되어 하위 호환성 보장
- 각 도구는 기존 v3 노드를 재사용하도록 fallback 구현
- 장기 메모리는 Redis가 없으면 로컬 캐시로 대체
- 최대 30회 iteration 후 강제 종료
