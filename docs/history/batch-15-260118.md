# Celery Backfill 작업 취소 기능 개선

> **Category**: batch
> **Date**: 2026-01-18
> **Status**: completed

---

## Context (배경)
- Backfill 작업 실행 후 UI에서 취소 버튼을 눌러도 실제로 작업이 계속 진행됨
- Admin에서 취소 시 DB의 `batch_jobs.status`가 `cancelled`로 변경되지만
- Celery 워커의 취소 체크가 불충분하여 작업이 중단되지 않음

### 문제점 분석
1. `_phase_search`: 취소 체크 없음 (검색 중 취소 불가)
2. `_phase_collect`: 루프 시작에만 취소 체크 (배치 처리 중 확인 안 함)
3. `_phase_embed`: 루프 시작에만 취소 체크 (배치 처리 중 확인 안 함)

## Solution (해결 방안)
- [x] `_phase_search`에 취소 체크 추가 (heartbeat 시점 + 배치 저장 전)
- [x] `_phase_collect`에서 배치 처리 후 취소 체크 추가
- [x] `_phase_embed`에서 배치 처리 후 취소 체크 추가

## Changes (변경 사항)
### 수정된 파일
- `batch/src/tasks/backfill.py`
  - `_phase_search`: heartbeat 체크 시점(30초 간격)에 취소 여부 확인
  - `_phase_search`: 배치 저장(100건) 전에 취소 여부 확인
  - `_phase_collect`: `asyncio.gather` 후 취소 여부 확인
  - `_phase_embed`: `asyncio.gather` 후 취소 여부 확인

### 취소 체크 포인트
| Phase | 체크 시점 | 빈도 |
|-------|----------|------|
| Search | heartbeat 시점 | 30초마다 |
| Search | 배치 저장 전 | 100건마다 |
| Collect | 루프 시작 | 매 루프 |
| Collect | 배치 처리 후 | max_concurrent건마다 |
| Embed | 루프 시작 | 매 루프 |
| Embed | 배치 처리 후 | max_concurrent건마다 |
