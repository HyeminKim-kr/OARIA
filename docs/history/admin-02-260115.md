# Admin 임베딩 진행상황 UI 개선

> **Category**: admin
> **Date**: 2026-01-15
> **Status**: completed

---

## Context (배경)

- Admin Papers 페이지에서 임베딩 작업 진행상황을 더 직관적으로 확인하고 싶음
- 기존 UI는 텍스트만 표시 (`진행: 12/50`)
- 프로그레스 바, 시간 정보, 에러 상세 등 개선 필요

## Solution (해결 방안)

### Backend API 확장
- `EmbedJobState` 타입에 `createdAt`, `chunkCount`, `heartbeat` 추가
- `JobStateResult` 타입에 `chunkCount` 추가
- Redis에서 이미 저장하고 있는 데이터 활용

### Frontend UI 개선
- 프로그레스 바 (시각적 진행률, CSS transition 애니메이션)
- 시간 정보 (경과 시간, 예상 완료 시간 계산)
- 청크 수 표시
- 에러 상세 보기 (접기/펼치기)
- 작업 있을 때 패널 자동 열림 (useEffect)

## Changes (변경 사항)

### Backend - 수정된 파일
- `admin/backend/src/modules/papers/types.ts` - EmbedJobState 타입에 createdAt, chunkCount, heartbeat 추가
- `admin/backend/src/modules/job-manager/job-manager.types.ts` - JobStateResult에 chunkCount 추가
- `admin/backend/src/modules/job-manager/job-manager.service.ts` - getJobState()에서 chunk_count 파싱 추가
- `admin/backend/src/modules/papers/papers.service.ts` - getEmbedJobs()에서 추가 필드 반환

### Frontend - 수정된 파일
- `admin/frontend/src/lib/api.ts` - EmbedJobState 타입 확장
- `admin/frontend/src/app/papers/page.tsx` - EmbedJobCard 사용, 자동 패널 열기
- `admin/frontend/src/app/papers/_components/index.ts` - EmbedJobCard export 추가

### Frontend - 생성된 파일
- `admin/frontend/src/app/papers/_components/EmbedJobCard.tsx` - 새 컴포넌트
  - 프로그레스 바 (색상: processing=blue, completed=green, failed=red)
  - 상태 배지 (queued, processing, completed, failed, cancelled)
  - 시간 정보 (시작 시간, 예상 완료 시간)
  - 청크 수 표시
  - 에러 메시지 표시 (접기/펼치기)
  - 상세 정보 패널 (Job ID, 생성/시작/완료 시간, 마지막 활동)
  - 재시도/취소 버튼

## Notes

- 폴링 간격 유지 (5초) - 실시간이 아닌 주기적 갱신
- 시간 계산은 프론트엔드에서 처리 (백엔드 부하 없음)
- 예상 완료 시간은 현재 처리 속도 기반 계산
