# Backfill Triple Producer-Consumer 패턴 적용

> **Category**: batch
> **Date**: 2026-01-15
> **Status**: completed

---

## Context (배경)

기존 Backfill 파이프라인 문제:
1. Phase 1 (Search)이 100% 완료된 후에만 Phase 2 (Collect) 시작
2. Collect가 100% 완료된 후에만 Embed 시작
3. 10만 건 검색 시 검색/수집 완료까지 임베딩 0건

**사용자 요청**: "서치하면 바로바로 다음작업 진행해야지", "논문 수집은 진행되는데 임베딩은 왜 안 돼?"

## Solution (해결 방안)

### Triple Producer-Consumer 패턴 적용

```
기존 (Sequential):
  Search (100%) ──► Collect (100%) ──► Embed (시작)

변경 (Triple Concurrent):
  Search ──────────────────────────────►
    │ (논문 등록)
    ▼
  Collect ◄────────────────────────────►
    │ (수집 완료)
    ▼
  Embed ◄──────────────────────────────►
    (즉시 임베딩)
```

### 동시성 제어
- `search_done`: 검색 완료 신호 (Collect에서 사용)
- `collect_done`: 수집 완료 신호 (Embed에서 사용)
- Polling: 선행 작업 진행 중에는 pending 없어도 대기

## Changes (변경 사항)

### 수정된 파일

- `batch/src/tasks/backfill.py`

  **1. Import 추가**
  ```python
  from .embed import (
      get_papers_for_embedding,
      process_single_paper_async,
      get_async_embedding_client,
  )
  from ..chunker import TextChunker
  from ..embedding import WeaviateClient, EmbeddingClient
  ```

  **2. `run_backfill_async()`: Triple Consumer 동시 실행**
  ```python
  search_done = asyncio.Event()
  collect_done = asyncio.Event()

  async def producer():
      await _phase_search(...)
      search_done.set()

  async def collect_consumer():
      result = await _phase_collect(..., search_done)
      collect_done.set()
      return result

  async def embed_consumer():
      return await _phase_embed(..., collect_done)

  await asyncio.gather(producer(), collect_consumer(), embed_consumer())
  ```

  **3. `_phase_embed()` 추가**: 수집과 동시에 임베딩 실행
  - `collect_done` 이벤트 기반 대기/종료 로직
  - 수집 진행 중 + pending 없음 → 3초 대기 후 재시도
  - 수집 완료 + pending 없음 (5회 연속) → 종료

  **4. Celery 태스크 수정**
  - `run_embed.delay()` 체이닝 제거 (이제 동시 실행됨)
  - 결과에 `embedded`, `embed_failed` 필드 추가
