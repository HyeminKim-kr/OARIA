## Root Cause Analysis

### Recursion 문제의 원인
1. `execute_node`가 `action_result`를 반환했지만, `StudyPlanState`에 해당 필드가 없었음
2. LangGraph가 unknown 필드를 무시하면서 `observe_node`에서 `action_result`가 None
3. `observe_node`가 상태 업데이트를 하지 못함 (특히 `structured_hypothesis`)
4. `check_goal`에서 goal 미달성으로 판단
5. 다시 `reason` → `parse_hypothesis` 선택 → 무한 반복

## Notes
- LangGraph는 TypedDict에 정의되지 않은 필드를 자동으로 저장하지 않음
- state에서 사용할 모든 필드는 반드시 TypedDict에 명시해야 함
- `recursion_limit`은 compile 시점에 설정 가능
