# Figure 인라인 배치 - fulltext와 동일한 위치

> **Category**: frontend
> **Date**: 2026-01-16
> **Status**: completed

---

## Context (배경)

논문 상세 페이지에서 Figure가 섹션 끝에만 배치되는 문제:
- 기존: 모든 문단 렌더링 → 마지막에 Figure들
- 요구: XML 원본과 동일한 위치에 Figure 인라인 배치

## Solution (해결 방안)

### 접근 방식: 통합 컨텐츠 배열

```
기존:
  DisplaySection {
    paragraphs: [...]   // 문단만
    figures: [...]      // Figure만 (섹션 끝에 배치)
  }

변경:
  DisplaySection {
    contents: [...]     // XML 순서대로 문단 + Figure 혼합
  }
```

## DisplayContent 구조

```typescript
interface DisplayContent {
  type: 'paragraph' | 'figure';
  // paragraph
  text?: string;
  // figure
  id?: string;
  label?: string;
  caption?: string;
  graphic_href?: string;
}
```

## 렌더링 로직

```tsx
{section.contents?.map((content, idx) => (
  content.type === 'figure' ? (
    <PaperFigure ... />   // Figure 인라인 렌더링
  ) : (
    <p>{content.text}</p>  // 문단 렌더링
  )
))}
```
