## Context (배경)

- 논문 상세 페이지에 Figure 이미지 및 유사 논문 추천 기능 추가 필요
- `/test` 폴더의 구현 가이드 및 테스트 코드 기반으로 작업
- Figure는 Hotlink 방식 (이미지 다운로드 없이 Europe PMC 서버 직접 참조)
- 유사 논문은 4가지 방식: Citation, Reference, Vector, Hybrid

## Solution (해결 방안)

### 접근 방식
1. **Figure Hotlink**: XML에서 `<fig>` 태그 파싱, Europe PMC 서버에서 직접 이미지 로드
2. **유사 논문 추천**: Europe PMC API (Citation/Reference) + Weaviate (Vector) 조합

## Notes

### Figure Hotlink URL 패턴
```
Primary:   https://europepmc.org/articles/PMC{pmcid}/bin/{graphic_href}.jpg
Fallback1: https://europepmc.org/articles/PMC{pmcid}/bin/{graphic_href}.png
Fallback2: https://www.ncbi.nlm.nih.gov/pmc/articles/PMC{pmcid}/bin/{graphic_href}.jpg
Fallback3: https://www.ncbi.nlm.nih.gov/pmc/articles/PMC{pmcid}/bin/{graphic_href}.png
```

### 유사 논문 추천 가중치
| 소스 | 가중치 | 설명 |
|------|--------|------|
| Citation | 1.0 | 후속 연구 (이 논문을 인용) |
| Reference | 0.8 | 기반 연구 (이 논문이 인용) |
| Vector | 0.6 + score | 내용 유사도 (Weaviate) |
