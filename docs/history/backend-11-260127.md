## Context (배경)

**핵심 문제:** LLM이 같은 행동을 무한 반복한다

**원인:** "지금 내가 어디 있는지" 모름 - 프롬프트에 Phase 정보가 없음

---

## 1차 목표 (이것만 하면 80% 해결)

```
1. Phase 정의 (6단계)
2. LLM 프롬프트에 "현재 Phase" 명시
3. Phase별 사용 가능한 도구 제한
4. Phase 전환 조건 체크
```

---

## Solution (설계)

### 1. Phase 정의

```python
from enum import Enum

class Phase(str, Enum):
    UNDERSTAND = "understand"    # 가설 파싱
    DECOMPOSE = "decompose"      # 질문 분해
    RESEARCH = "research"        # 문헌 검색
    DESIGN = "design"            # 실험 설계
    VALIDATE = "validate"        # 검증
    SYNTHESIZE = "synthesize"    # 최종 합성
    COMPLETED = "completed"
```

### 2. Phase별 도구 & 전환 조건

| Phase | 사용 가능 도구 | 전환 조건 |
|-------|---------------|----------|
| UNDERSTAND | `parse_hypothesis` | structured_hypothesis 존재 |
| DECOMPOSE | `decompose_questions` | test_questions >= 3 |
| RESEARCH | `search_rag`, `search_epmc`, `search_web` | 각 질문에 evidence 존재 OR 3회 시도 |
| DESIGN | `design_experiment`, `design_controls`, `suggest_measurements` | experiments >= 1 |
| VALIDATE | `critique_design`, `validate_feasibility` | quality_score >= 0.7 |
| SYNTHESIZE | `synthesize_plan`, `generate_plan_b` | plan_a AND plan_b 존재 |

### 3. LLM 프롬프트에 Phase 정보 추가 (핵심!)

```python
PHASE_CONTEXT_PROMPT = """
```

### 4. Phase Tracker (간단 버전)

```python
@dataclass
class PhaseState:
    current_phase: Phase
    completed_phases: set[Phase]
    tool_calls: dict[str, int]  # {"search_rag": 3}

class PhaseTracker:
    def __init__(self, state: WorkingMemory):
        self.state = state

    def get_current_phase(self) -> Phase:
        """현재 Phase 판단"""
        if not self.state.structured_hypothesis:
            return Phase.UNDERSTAND
        if len(self.state.test_questions) < 3:
            return Phase.DECOMPOSE
        if not self._has_enough_evidence():
            return Phase.RESEARCH
        if len(self.state.experiments) < 1:
            return Phase.DESIGN
        if self.state.quality_score < 0.7:
            return Phase.VALIDATE
        if not (self.state.plan_a and self.state.plan_b):
            return Phase.SYNTHESIZE
        return Phase.COMPLETED

    def get_allowed_tools(self, phase: Phase) -> list[str]:
        """Phase별 허용 도구"""
        PHASE_TOOLS = {
            Phase.UNDERSTAND: ["parse_hypothesis"],
```

## 강제 전환 로직 (무한루프 방지)

### Phase Guard (`reason.py:298-340`)
LLM이 현재 Phase에서 허용되지 않은 도구를 선택하면:
```
decompose_questions (DECOMPOSE) → parse_hypothesis (UNDERSTAND)로 강제 리다이렉트
```

### Anti-Infinite-Loop (`reason.py:342-397`, `phase_tracker.py:181-248`)
같은 Phase에서 막힘 감지 시 다음 Phase로 강제 전환:
```python
# 강제 전환 조건:
1. 모든 허용 도구가 3회+ 실패
2. 같은 도구가 4회 연속 호출 (루프 감지)
3. Phase별 iteration 한도 초과:
   - UNDERSTAND: 5회
   - DECOMPOSE: 8회
   - RESEARCH: 15회
   - DESIGN: 20회
   - VALIDATE: 25회
   - SYNTHESIZE: 30회
```

### Bug 1: decompose_questions 파라미터 불일치
**파일**: `executor.py:179-184`
**원인**: auto_fill에서 `hypothesis` 키 사용, 하지만 도구는 `structured_hypothesis` 기대
**수정**:

```python
# BEFORE

# AFTER

```

### Bug 2: RESEARCH Phase 무한 루프
**파일**: `phase_tracker.py:113-137`
**원인**: `_has_enough_evidence()` 함수가 항상 False 반환
- `self._tool_calls`가 매 iteration마다 새 인스턴스 → 항상 비어있음
- `evidence.get("question_id")`는 검색 결과에 존재하지 않는 키
**수정**:
```python
# 단순화된 조건으로 변경
def _has_enough_evidence(self) -> bool:
    if self.state.evidence_snippets and len(self.state.evidence_snippets) >= 1:
        return True
    if self.state.retrieved_papers and len(self.state.retrieved_papers) >= 3:
        return True
    if self.state.iteration_count >= 10:
        return True
    return False
```

### Bug 3: Plan B 무한 루프
