# 환경변수 가이드 및 타입 강화

> **Category**: admin
> **Date**: 2025-12-31
> **Status**: completed

---

## Context (배경)
- .env.example에 인프라 환경변수 가이드가 없음
- Controller DTO에 class-validator 유효성 검사 없음
- Service 타입이 느슨한 interface로만 정의됨

## Solution (해결 방안)
- [x] .env.example 전체 환경변수 가이드 추가
- [x] System 모듈 DTO class-validator 적용
- [x] Service 타입 강화 (enum, strict interface)

## Changes (변경 사항)

### 생성된 파일
- `admin/backend/src/modules/system/types.ts` - 타입/enum 정의
  - `ServiceHealthStatus` enum (healthy, unhealthy, unknown)
  - `SystemHealthStatus` enum (healthy, degraded, unhealthy)
  - `CeleryWorkerStatus` enum (online, offline)
  - `ServiceName` enum (PostgreSQL, Redis, Weaviate, MinIO, Celery)
  - `ServiceStatus`, `SystemHealth`, `CeleryWorkerInfo`, `CeleryQueueInfo`, `TaskTriggerResult` interfaces

- `admin/backend/src/modules/system/dto/index.ts` - class-validator DTOs
  - `TriggerEmbeddingDto` - limit 필드 유효성 검사 (1-500)
  - `TriggerReembeddingDto` - limit 필드 유효성 검사 (1-500)

### 수정된 파일
- `.env.example` - 전체 인프라 환경변수 가이드 추가
  - Database (PostgreSQL)
  - Redis
  - Object Storage (MinIO/S3)
  - Vector Database (Weaviate)
  - Celery Monitoring (Flower)
  - OpenAI API
  - Admin Backend (JWT, Google OAuth)
  - Docker Compose 포트 매핑 참고

- `admin/backend/src/modules/system/system.service.ts`
  - types.ts에서 enum, interface import
  - 모든 check* 메서드에서 enum 사용 (ServiceName, ServiceHealthStatus)
  - getCeleryWorkers에서 CeleryWorkerStatus enum 사용
  - triggerEmbedding/triggerReembedding 반환 타입 `TaskTriggerResult`로 명시

- `admin/backend/src/modules/system/system.controller.ts`
  - 인라인 TriggerEmbeddingDto 제거
  - dto/index.ts에서 DTO import
  - TaskTriggerResult 타입 import
  - 트리거 메서드에 명시적 반환 타입 추가
