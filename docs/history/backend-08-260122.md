## Notes

- 테스트는 `pytest` 기반으로 작성
- 외부 API 호출이 필요한 테스트는 mock 처리
- LLM 호출 테스트는 비용 고려하여 선택적 실행 (`@pytest.mark.slow`)
- 테스트 실행: `uv run pytest tests/agent/study_plan/v4/ -v`

### 프론트엔드 v4 연동 현황 (2026-01-22 확인)

| 항목 | 현재 상태 | 비고 |
|------|----------|------|
| 프론트엔드 API | v3 사용 중 | `generateV3` 호출 |
| 백엔드 v4 엔드포인트 | ✅ 존재 | `/generate-v4`, `/generate-v4-stream` |
| v4 타입 정의 (FE) | ❌ 없음 | api.ts에 v4 타입 미정의 |
| SSE 스트리밍 (FE) | ❌ 미구현 | 시뮬레이션 처리 중 |
| 히스토리 페이지 | ✅ 정상 | `/study-plan/history` 작동 |

**결론**: 프론트엔드는 v4 미연동 상태. 백엔드 v4 API는 준비됨.
