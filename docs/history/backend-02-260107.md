# RAG 모듈 모듈화 (Strategy + Registry Pattern)

> **Category**: backend
> **Date**: 2026-01-07
> **Status**: completed (Phase 4 완료)

---

## Context (배경)

- Admin Lab에서 RAG 품질 개선을 위해 다양한 전략(청킹, 임베딩, 리랭커 등)을 선택할 수 있어야 함
- 팀원들이 새로운 전략/모델을 쉽게 추가할 수 있도록 모듈화 필요
- Claude Code가 README를 읽고 쉽게 새 컴포넌트를 추가할 수 있는 구조 설계
- 기존 서비스들(`embedding_service`, `reranker_service`, `weaviate_service`)을 RAG 모듈로 래핑

### 참고 문서
- `backend/app/rag/README.md` - RAG 모듈 개발 가이드
- Jira Epic: OAR-11 [F-03] Evidence RAG 시스템
