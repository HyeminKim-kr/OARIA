# 유사 논문 Lazy Loading 성능 개선

> **Category**: frontend
> **Date**: 2026-01-16
> **Status**: completed

---

## Context (배경)

유사 논문 탭("유사 논문")의 로딩이 매우 느림 (5-12초):
- Europe PMC API 호출이 순차적으로 실행됨 (각 2-5초)
- 탭 전환 시마다 새로 API 호출 (캐싱 없음)
- Hybrid 모드가 기본값으로 모든 소스를 한번에 로드

## Solution (해결 방안)

### Lazy Loading + References 우선 전략

1. **기본 탭을 References로 변경** (빠른 DB 조회)
2. **소스별 독립 상태 관리** - 각 탭의 데이터를 개별 관리
3. **On-demand 로딩** - 탭 클릭 시에만 해당 데이터 로드
4. **In-memory 캐싱** - 한번 로드한 데이터는 탭 전환 시 재사용

### 새 로딩 흐름

```
"유사 논문" 탭 클릭
    ↓
[즉시] References 탭 표시 + 로딩 시작
    → 빠르게 결과 표시 (~100ms - DB 조회)
    ↓
[사용자 선택 시] 다른 탭 클릭
    → 해당 소스만 로드
    → 캐시 있으면 즉시 표시
```

## Changes (변경 사항)

- `frontend/src/components/papers/SimilarPapers.tsx`

  - 탭 순서: References, Citations, Vector, Hybrid
  - 소스별 독립 상태 관리 (`SourceLoadingState` 인터페이스)

  - In-memory 캐싱 (`loaded` 플래그)
  - paperId 변경 시 캐시 초기화
  - 탭별 로딩 스피너 표시
