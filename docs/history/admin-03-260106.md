> **Category**: admin
> **Date**: 2026-01-06
> **Status**: completed

---

## Context (배경)

RAG Lab에서 테스트한 쿼리와 결과가 매번 사라져서 품질 관리에 활용할 수 없음.
피드백(👍/👎)만 저장되고, 실제 검색 결과는 저장되지 않아서 품질 변화 추적 불가.

### 요구사항
- 테스트 실행 시 결과 자동 저장
- 테스트 히스토리 조회 기능
- 불필요한 로그 삭제 기능

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /lab/logs | 테스트 로그 목록 조회 (페이지네이션, 필터링) |
| GET | /lab/logs/:id | 테스트 로그 상세 조회 |
| DELETE | /lab/logs/:id | 테스트 로그 삭제 |
| GET | /lab/stats/feedback | 피드백 통계 조회 |
| GET | /lab/stats/logs | 테스트 로그 통계 조회 |
| POST | /lab/compare | A/B 비교 테스트 (Reranker ON vs OFF) |
