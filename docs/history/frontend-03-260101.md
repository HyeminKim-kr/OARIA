## Context (배경)

- Reference 모달에서 풀텍스트 표시 시 가독성 문제
- 원본 논문은 단락, 헤딩 등 구조화되어 있음
- 현재는 플레인 텍스트로 한 덩어리로 표시
- 이미 fulltext에 `[SECTION]` 형식 헤더 존재 (임베딩 파이프라인에서 생성)

## 오프셋 불일치 문제 (발견 및 해결)

### 문제
- Weaviate의 offset: **fulltext 기준** (예: 1948-4741)
- XML 파싱 offset: **섹션 기준** (예: 0-4206)
- 프론트엔드에서 fulltext 오프셋으로 섹션 텍스트에 하이라이트 시도 → 불일치!

### 해결
- API 응답에 `section_fulltext_offset` 필드 추가
- 프론트엔드에서 오프셋 변환: `adjustedOffset = referenceOffset - sectionFulltextOffset`
- 변환된 오프셋으로 정확한 하이라이트 표시
