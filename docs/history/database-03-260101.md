# 배치 테이블 명명 규칙 통일 (batch_* 접두사)

> **Category**: database
> **Date**: 2026-01-01
> **Status**: completed

---

## Context (배경)

- 기존에 OAR-21에서 `batch_jobs`로 설계
- OAR-22에서 `collection_jobs`로 변경됨
- 관련 테이블들이 혼재:
  - `collection_jobs` (메인)
  - `article_jobs` (FK: batch_job_id)
  - `batch_job_logs`
  - `batch_failed_items`
  - `article_errors`
- 명명 규칙 불일치로 혼란 발생

## Solution (해결 방안)

### `batch_*` 접두사로 통일

**이유:**
1. 업계 표준 용어 ("batch job"이 "collection job"보다 익숙)
2. 범용성 (임베딩/인덱싱 등 다른 배치로 확장 가능)
3. 기존 `batch_*` 테이블이 더 많음
4. OAR-21 원본 설계 복원

### 변경 계획

| 현재 | 변경 후 | 비고 |
|------|--------|------|
| `collection_jobs` | `batch_jobs` | 메인 테이블 |
| `article_jobs` | `batch_articles` | FK: job_id |
| `article_errors` | `batch_errors` | 에러 로그 |
| `batch_job_logs` | `batch_logs` | 간소화 |
| `batch_failed_items` | 유지 | 이미 규칙 준수 |
