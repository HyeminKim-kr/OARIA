# 하이라이트 컨텍스트 미반영 버그 수정

> **Category**: backend
> **Date**: 2026-01-30
> **Status**: completed

---

## Context (배경)
- 논문 상세 페이지의 AI Assistant에서 "하이라이트 & 질문" 기능이 제대로 동작하지 않음
- 사용자가 텍스트를 드래그(하이라이트)하고 질문하면, 해당 선택 텍스트를 기반으로 답변해야 하는데 일반적인 요약 답변만 제공
- 프론트엔드에서 `highlight_context`를 정상적으로 전송하지만 백엔드에서 완전히 무시하고 있었음

## Solution (해결 방안)
- [x] `PAPER_CHAT_HIGHLIGHT_PROMPT` 전용 프롬프트 추가 - 선택 텍스트를 최우선 참고하도록 지시
- [x] RAG 쿼리에 하이라이트 텍스트 앞부분 포함 - 관련 섹션 검색 정확도 향상
- [x] 프롬프트 분기 처리 - `has_highlight` 여부에 따라 적합한 프롬프트 선택

## Changes (변경 사항)
### 수정된 파일
- `backend/app/routers/paper_chat.py`
  - `PAPER_CHAT_HIGHLIGHT_PROMPT` 추가: 하이라이트 전용 시스템 프롬프트 (선택 텍스트 우선 참고 지시)
  - RAG 쿼리 개선: `highlight_context[:200]`을 쿼리 앞에 추가하여 해당 섹션 근처 결과 우선 검색
  - 프롬프트 분기: `has_highlight` 플래그로 일반/하이라이트 프롬프트 선택

## Notes
- 프론트엔드 코드(`PaperChatPanel.tsx`, `usePaperChat.ts`)는 이미 `highlight_context`를 정상 전송하고 있어 수정 불필요
- 스키마(`PaperAskRequest`)도 이미 `highlight_context` 필드 정의되어 있음
