# Study Plan Agent - SSE 스트리밍 중간 단계 데이터 구현

> **Category**: frontend
> **Date**: 2026-01-22
> **Status**: completed

---

## Context (배경)

Study Plan Agent v3에서 활동 사이드바가 추가되었으나, 시뮬레이션된 메시지만 표시되고 있었음. 사용자가 실제 중간 단계 데이터(가설 파싱 결과, 검증 질문, 검색 결과 등)를 보고 싶다고 요청함.

### 문제점

1. 프론트엔드가 동기 API (`/generate-v3`)를 사용하여 최종 결과만 수신
2. 백엔드에 SSE 스트리밍 인프라가 있었으나 v3용 엔드포인트 없음
3. 활동 사이드바에 시뮬레이션 메시지만 표시

---

## Solution (해결 방안)

### 백엔드 변경

1. **`service.py`** - `execute_stream_v3` 메서드 추가
   - v3 그래프를 스트리밍 모드로 실행
   - `_create_node_event_v3` 헬퍼로 상세 중간 데이터 포함

2. **`study_plan.py` (router)** - `/generate-v3-stream` 엔드포인트 추가
   - SSE 스트리밍으로 각 노드의 상세 데이터 반환
   - 각 이벤트에 `detail` 필드로 사람이 읽을 수 있는 요약 포함

### 프론트엔드 변경

1. **`api.ts`**
   - `StudyPlanSSEEvent` 타입 정의 (모든 중간 단계 필드)
   - `generateV3StreamUrl()` 추가

2. **`page.tsx`** - `handleSubmit` 함수 SSE 기반으로 전환
   - `fetchWithAuth`로 SSE 스트리밍 연결
   - 실시간으로 각 노드의 실제 데이터를 활동 로그에 표시

---

## Changes (변경 사항)

### 수정된 파일

**Backend:**

  - `execute_stream_v3()` 메서드 추가
  - `_create_node_event_v3()` 헬퍼 추가 (상세 데이터 포함)

- `backend/app/routers/study_plan.py`
  - `/generate-v3-stream` POST 엔드포인트 추가

**Frontend:**
- `frontend/src/lib/api.ts`
  - `StudyPlanSSEEvent` 인터페이스 추가
  - `generateV3StreamUrl()` 추가

- `frontend/src/app/agents/study-plan/page.tsx`
  - `handleSubmit` 함수를 SSE 스트리밍 기반으로 변경
  - 실제 중간 데이터를 활동 로그에 표시

## 활동 사이드바에 표시되는 실제 데이터

| 노드 | 표시 내용 |
|------|----------|
| parse_hypothesis | 독립변수, 종속변수, 핵심 키워드 |
| decompose_tests | 생성된 검증 질문 수, 카테고리 (NSPE) |
| search_studies | 검색 티어, 발견 논문 수, 커버리지 %, 부족 영역 |
| build_evidence | 논문 수, 스니펫 수 |
| design_experiments | 실험 수, 유형, 각 실험 제목 |
| critique_refine | 품질 점수 %, 통과 여부, 개선 제안 |
| validate_feasibility | 실현가능성 점수 % |
| synthesize_plan | Plan A/B 여부, 소요 시간 |
