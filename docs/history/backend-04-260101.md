## Context (배경)

- Chat/RAG API 연동 완료, SSE 스트리밍 동작 확인
- 사용자 피드백: RAG 검색 중 대기 시간이 길게 느껴짐
- 현재는 검색 완료 후에야 스트림이 시작되어 피드백 없음

## Solution (해결 방안)

### 접근 방식
SSE 스트림을 즉시 시작하고 각 단계별로 status 이벤트 전송:
```
event: status → "논문 검색 중..."
event: references → 검색 결과
event: status → "답변 생성 중..."
event: token → 토큰 스트리밍
event: done → 완료
```
